# Oppskriftslista

Oppskriftslista er en moderne og brukervennlig oppskriftsapp bygget med React, TypeScript og Vite. Applikasjonen lar deg samle, redigere, søke og organisere alle dine favorittoppskrifter på ett sted.

## Funksjoner

- **Oppskriftsoversikt**: Rask og responsiv visning av alle oppskrifter med forsidebilde, tilberedningstid, vanskelighetsgrad og tagger.
- **Søk & Filtrering**: Filtrer etter kategori (Frokost, Lunsj, Middag, Dessert, Vegansk) og maksimal tilberedningstid, eller søk på tittel, ingredienser og tagger i sanntid.
- **Detaljert oppskriftsvisning**:
  - Oversikt over forberedelsestid, steketid, porsjoner og vanskelighetsgrad.
  - Interaktiv sjekkliste for ingredienser med gjennomstreking.
  - Steg-for-steg fremgangsmåte.
- **Legg til & Rediger oppskrifter**: Enkelt skjema med dynamisk håndtering av ingredienser og instruksjoner samt støtte for bilde-URL eller lokal bildeopplasting.
- **Eksport & Import**: Eksporter oppskrifter som JSON og importer eksisterende oppskriftsfiler.
- **Lys / Mørk modus**: Full støtte for både mørkt og lyst tema tilpasset dine preferanser.
- **Lokal lagring**: Data lagres trygt i nettleserens `localStorage`.

## Teknologi

- React 19
- TypeScript
- Vite
- CSS3 med variabler for dynamisk fargetema
